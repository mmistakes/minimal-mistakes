Clean code is rarely written clean on the first pass. This chapter walks the Args parser example: start with something that works, then successively refine structure, names, and responsibilities.

## Takeaways

- First drafts can be messy; stopping there is the failure mode
- Refactor in small, test-backed steps
- Let tests unlock fearless cleanup
- Aim for modules that each express one clear idea

The craft is not avoiding mess forever — it is recognizing mess and systematically deleting it.
